(upward drizzle), one concrete number, one straight-faced official instruction.

## Run it

```sh
python3 main.py
```

Writes the forecast to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`),
validates it against the gate (single line, 1–160 characters, not only whitespace),
then reads it back and checks the bytes match.
